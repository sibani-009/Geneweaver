# GeneWeaver

## GPU-Accelerated CRISPR Alignment Engine

GeneWeaver is a Python-based bioinformatics project
designed to identify potential off-target DNA matches.

## Project Objectives

- Read DNA sequences from FASTA files.
- Divide genome sequences into manageable chunks.
- Perform DNA alignment using Python.
- Measure CPU execution time.
- Accelerate DNA alignment using Numba CUDA.
- Display alignment progress through a Textual dashboard.

## Technologies Used

- Python
- BioPython
- NumPy
- Numba CUDA
- Textual
